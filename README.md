# 🏫 University Website
University Website is a fully responsive website designed to provide a modern and user-friendly experience for students, and visitors. The website offers essential university information, course details, and contact options in a structured and visually appealing layout.

## ✨ Features
- Fully responsive design for mobile and desktop
- Clean and professional UI/UX
- Information about university programs and courses
- Sections for Courses, Campus Detail, Facilities and contact details
- Easy navigation for users

## 🛠 Technologies Used
- **HTML** – Structure of the website
- **CSS** – Styling and layout design
- **Netlify** – Hosting platform
- **Git & GitHub** – Version control and code management

## 🌐 Live Demo
Check out the live website: [University Website](https://eduford-for-you.netlify.app/)

## 📌 How to Use
1. Open the website link in any modern browser.
2. Navigate through the sections to explore university programs and information.
3. Contact the university for further inquiries.
